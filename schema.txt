CGPS SCHOOL APP — FIRESTORE SCHEMA
====================================
Firestore database ID: "school-app"
Project: spring2026project

Brief your AI assistant with this file every time you work on reads/writes.
All collections live in the "school-app" Firestore database (see firebase-config.ts).

====================================
COLLECTION: studyBuddies_users
====================================
Owner: Armen
Purpose: Tracks whether each student has opted in to the Study Buddies matching system.
         Written when a student clicks "Join" or "Browse only" on the opt-in screen.
         Read on app load to restore their saved preference.

Document ID: student email address (e.g. "aazadian27@cgps.org")

Fields:
  - studentId   : number   — numeric ID from the schedule CSV (e.g. 121450)
  - name        : string   — "Last, First" format, matches the CSV (e.g. "Azadian, Armen")
  - email       : string   — CGPS Google email (e.g. "aazadian27@cgps.org")
  - optedIn     : boolean  — true = visible to matches; false = hidden/browse-only
  - updatedAt   : timestamp — Firestore server timestamp of last opt-in change

Example document (id: "aazadian27@cgps.org"):
  {
    studentId: 121450,
    name: "Azadian, Armen",
    email: "aazadian27@cgps.org",
    optedIn: true,
    updatedAt: <Firestore Timestamp>
  }

====================================
COLLECTION: rooms
====================================
Owner: Jake / Jonny
Purpose: Stores each physical room with its full daily schedule (multiple classes),
         live study-space occupancy, and the list of office hours sessions and
         student bookings happening in it. Seed documents manually or via script.
         currentOccupancy is updated in real-time as students book/unbook a study spot.

Document ID: roomNumber string (e.g. "302W")

Fields:
  - roomNumber       : string  — room code (e.g. "302W")
  - capacity         : number  — max students allowed for study-space bookings
  - currentOccupancy : number  — live count of active study-space bookings

  - classes          : array of objects — ALL classes scheduled in this room throughout the day.
                       Each object has:
                         { className: string,   — e.g. "Algebra II"
                           teacher:   string,   — e.g. "Mr. Anderson"
                           start:     string,   — 24-hour "HH:MM" (e.g. "09:15")
                           end:       string }  — 24-hour "HH:MM" (e.g. "10:00")

  - officeHours      : array of objects — office hours sessions held in this room.
                       Each object mirrors the officeHours collection fields:
                         { officeHourId: string,   — Firestore doc ID from officeHours collection
                           teacherName:  string,
                           subject:      string,
                           day:          string,   — "Monday" | "Tuesday" | etc.
                           start:        string,
                           end:          string }

  - bookings         : array of objects — active study-space bookings in this room.
                       Each object mirrors the roomBookings collection fields:
                         { bookingId:  string,   — Firestore doc ID from roomBookings collection
                           userEmail:  string,
                           bookedAt:   timestamp }

Example document (id: "302W"):
  {
    roomNumber: "302W",
    capacity: 20,
    currentOccupancy: 2,
    classes: [
      { className: "Algebra II",  teacher: "Mr. Anderson", start: "09:15", end: "10:00" },
      { className: "Calculus",    teacher: "Ms. Rivera",   start: "11:00", end: "11:45" },
      { className: "Statistics",  teacher: "Mr. Chen",     start: "13:20", end: "14:10" }
    ],
    officeHours: [
      { officeHourId: "abc123", teacherName: "Mr. Anderson", subject: "Algebra II",
        day: "Monday", start: "08:00", end: "08:45" }
    ],
    bookings: [
      { bookingId: "xyz789", userEmail: "aazadian27@cgps.org", bookedAt: <Timestamp> }
    ]
  }

NOTE: officeHours and bookings are also stored in their own top-level collections
(officeHours and roomBookings). The arrays here are a convenience copy so you can
display everything about a room in one read. When a booking or office hour is
added/removed, update BOTH the top-level collection AND this array.

====================================
COLLECTION: roomBookings
====================================
Owner: Jake / Jonny
Purpose: Records each active room booking. Written when a student books a room.
         Deleted (or marked inactive) when they unbook.
         Query by userEmail to check if a student already has a booking.

Document ID: auto-generated by Firestore

Fields:
  - userEmail  : string    — the logged-in student's Google email
  - roomNumber : string    — matches the document ID in the "rooms" collection
  - bookedAt   : timestamp — Firestore server timestamp of when the booking was made

Example document:
  {
    userEmail: "aazadian27@cgps.org",
    roomNumber: "302W",
    bookedAt: <Firestore Timestamp>
  }

Query example — check if user already has a booking:
  where("userEmail", "==", currentUser.email)

====================================
COLLECTION: officeHours
====================================
Owner: Jake / Jonny
Purpose: Teacher-posted office hours sessions. Written when a teacher submits the
         "Post Office Hours" form. Read to display the office hours list to students.

Document ID: auto-generated by Firestore

Fields:
  - teacherName : string — full name (e.g. "Mr. Anderson")
  - subject     : string — class or subject (e.g. "AP Biology")
  - day         : string — day of the week: "Monday" | "Tuesday" | "Wednesday" | "Thursday" | "Friday"
  - start       : string — 24-hour start time "HH:MM" (e.g. "08:00")
  - end         : string — 24-hour end time "HH:MM" (e.g. "08:45")
  - room        : string — room number (e.g. "302W")
  - postedAt    : timestamp — Firestore server timestamp of when the entry was created

Example document:
  {
    teacherName: "Mr. Anderson",
    subject: "Algebra II",
    day: "Monday",
    start: "08:00",
    end: "08:45",
    room: "302W",
    postedAt: <Firestore Timestamp>
  }

====================================
COLLECTION: officeHourRSVPs
====================================
Owner: Jake / Jonny
Purpose: Tracks which students have RSVP'd to which office hours sessions.
         Written when a student clicks "RSVP". Deleted when they click "Cancel RSVP".
         Query by userEmail to restore RSVP state on page load.

Document ID: auto-generated by Firestore

Fields:
  - userEmail     : string    — the logged-in student's Google email
  - officeHourId  : string    — the Firestore document ID from the officeHours collection
  - rsvpAt        : timestamp — Firestore server timestamp

Example document:
  {
    userEmail: "aazadian27@cgps.org",
    officeHourId: "abc123xyz",
    rsvpAt: <Firestore Timestamp>
  }

Query example — load all RSVPs for the current user:
  where("userEmail", "==", currentUser.email)

====================================
NOTES FOR ALL DEVELOPERS
====================================
Import "db" from "@/firebase-config" for all Firestore calls.
Use serverTimestamp() from "firebase/firestore" for all timestamp fields.
The Firestore database ID is "school-app" — already set in firebase-config.ts.
Do NOT store full schedule/class data in Firestore. The CSV (parseSchedule.ts)
  is the source of truth for class schedules. Firestore only stores user state
  (opt-in choices, bookings, RSVPs, teacher-posted entries).
If you change this schema, update this file AND ask your AI to write a migration
  script to update existing documents.
